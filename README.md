# BDG PREDICTOR

Android app that loads **https://bdg.colourtradinghack.com/** in a full WebView.
Package: `com.colourtradinghack.bdg.app` · Version: `2.200.2 (1)` · Build: APK without Firebase

Generated by Site2App. The project contains no watermark, badge or third-party branding.

## Get the APK without installing anything (GitHub)

1. Create a new repository on GitHub and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab, choose **Build APK** and press **Run workflow**. It also runs on every push.
3. When the run finishes, open it and download the `bdg-predictor-apk` artifact. The `.apk` inside installs on any Android phone (allow "Install unknown apps" for your file manager).

The workflow signs the APK with a temporary key. To keep a stable identity for updates or Google Play, create your own keystore and add these repository secrets: `KEYSTORE_BASE64` (the .jks file, base64-encoded), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

## Or build on your computer

Open this folder in Android Studio (Koala or newer, JDK 17). If it asks for a Gradle version, pick 8.7 or newer. Then use **Build > Generate Signed App Bundle / APK**, or run `gradle assembleDebug` for a quick test build.

## Change a setting later

Everything chosen in the builder is in `app/src/main/java/com/colourtradinghack/bdg/app/AppConfig.java`: start URL, zoom, rotation, keep screen on, full screen, pull to refresh, splash timing and the link rules. Edit it and rebuild.

Link rules run from top to bottom and the first match wins. After the rules, pages on the same domain as the start URL stay inside the app (if enabled), and everything else follows the default action. `tel:`, `mailto:`, `sms:`, `geo:` and app deep links always open in the matching app.

## Icons and splash

`app/src/main/res/mipmap-*` hold the launcher icon. `res/drawable-nodpi/splash_logo.png` is the splash logo. A 512 x 512 copy for Google Play is in `store/icon-512.png`.

## Firebase

This build has no Firebase code or Google services plugin. To add push notifications later, generate the project again with the Firebase option and your `google-services.json`.
